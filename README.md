# Focus & Save — Smart Reader & Bookmark Manager

A local-first Chrome extension (Manifest V3) with an on-demand reader overlay and a bookmark dashboard.

## Features included in this starter project

- Reader overlay injected only after a user action (`activeTab` + `scripting`).
- Mozilla Readability article extraction and DOMPurify sanitization.
- Reader theme, font, font size, line height, content width, alignment and paragraph spacing controls.
- Save current page from the popup, reader, or right-click context menu.
- Local bookmark storage, duplicate URL handling, favorites, categories, tags, notes and reading status.
- Dashboard search, category filter, edit and delete.
- JSON export/import with input validation.
- Vitest + JSDOM tests for validation and storage.

## Requirements

- Node.js 20 or later recommended
- npm
- Google Chrome

## Install and build (Windows CMD)

```cmd
cd /d C:\Projects\focus-and-save
npm install
npm run build
npm test
```

`npm install` creates `package-lock.json`. Commit this file to Git; do not add it to `.gitignore`.

## Load in Chrome

1. Run `npm run build` first. This creates `dist/reader.bundle.js`.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Choose **Load unpacked**.
5. Select the project folder `C:\Projects\focus-and-save`.
6. Open a normal HTTP/HTTPS webpage and click the extension icon.
7. Choose **Open / Close Reader**. Click it again to close the reader.
8. Use **Open bookmark dashboard** to manage saved pages.

Reader injection is not available on Chrome internal pages, the Chrome Web Store, PDF viewer pages, or other restricted browser surfaces.

## Privacy and security notes

- Bookmark records are stored with `chrome.storage.local`; this project has no account or remote sync implementation.
- Reader code is injected only after a user action; it is not registered as an automatic content script.
- DOMPurify is used to sanitize extracted article HTML. Keep the dependency updated and review its configuration when changing supported content.
- Imported JSON is validated before storage, but always keep backups of important data.
- Do not publish privacy or Chrome Web Store claims until you have tested the exact release build and reviewed current store requirements.
